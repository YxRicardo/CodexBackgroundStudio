# Codex Background Studio 1.0.6

这是一个 Windows 本地主题编辑器，用于为 Codex 桌面应用配置首页、对话和侧栏背景。它是独立项目，**不是 OpenAI 官方扩展**。

## 从源码运行

需要 Node.js 22.4 或更高版本，以及可访问的 Codex 桌面应用。

```powershell
node .\app\server.mjs
```

然后在浏览器中打开 `http://127.0.0.1:47831`。本地发布包中的 `BackgroundStudio.exe` 和 `Start.cmd` 仅用于免安装运行，不包含在源码仓库。

程序和所有工作文件位于 D:\Codex_Background。无需安装 Node.js；附带 Node.js 24.19.0。界面通过本机 Edge 应用窗口打开，未找到 Edge 时使用默认浏览器。它是 Windows 启动器加本地网页界面的桌面工具，不是 Codex 官方扩展。

## 使用

1. 左侧选择首页、对话、侧栏或配色与面板。
2. 选择纯色、渐变或图片；支持 PNG、JPEG、WebP，每张最大 6MB。图片保存在配置内，原文件移动后仍可使用。
3. 调节位置、缩放、模糊、背景不透明度和遮罩。对话默认跟随首页；取消勾选后可独立调整。
4. 点击“应用到 Codex”。应用后执行真实验证，失败会尝试回退到上一主题。
5. 首次应用成功后，可勾选“调整后自动应用到 Codex”。连续滑动会合并更新。

预览使用示例内容，不读取实际对话。窗口尺寸、原生组件和代码语法颜色会使预览与真实页面略有差异。高遮罩强度更适合阅读。

## 保存与导出

- **保存草稿**：保存编辑参数，不改变当前应用的主题。
- **收藏当前方案**：生成一个独立预设；同名方案也能分别保存。
- **导出**：在 exports 下同时生成 `.codedrobe-theme` 分享包和 `.json` 可编辑配置。
- **导入**：选择此前导出的 `.json`。任意第三方 CSS 主题无法自动还原成可调节参数，因此不作为第一版的可编辑导入格式。
- **撤销应用**：返回上一次成功应用的方案；再次点击可在最近两次方案之间切换。

## 连接、保持与恢复

程序仅监听 127.0.0.1:47831，主题连接使用 9335。现有连接可直接应用。若显示未连接，在“恢复与运行管理”中使用“连接 Codex（必要时重启）”。此操作可能中断当前运行任务，选择方便的时机操作。

关闭调节窗口后，本地服务继续保持当前主题。它不会添加开机启动；电脑重启后再次打开本程序即可恢复保持。运行中的目录不要移动。

- **恢复接管前主题**：重新应用首次接管 AzureReverie 监听器时备份的主题。
- **恢复 Codex 原生外观**：停止保持、移除主题层，并调用 Core 的原生配色还原。若提示需要重开，请完全退出并重开 Codex。
- **停止自动保持**：停止主题监听，当前页面暂时保留样式；页面重新加载后可能消失。
- **Stop.cmd**：关闭本程序的后台服务。只核对并结束本程序记录的进程。若希望恢复原生外观，应先在界面点击恢复，再停止服务。

本程序不改 Codex 安装文件、认证或任务内容。正常编辑使用独立 CSS 层，不持续改写基础配色配置。第一次接管仅停止 PID 和完整命令行均匹配的旧 AzureReverie 监听器。

## 文件夹

| 目录 | 内容 |
|---|---|
| app | 界面、主题引擎、独立 Core 和原始模板 |
| runtime | 自带 Node.exe 及许可证 |
| data | 草稿、预设、应用状态和回退备份 |
| exports | 用户导出的主题与编辑配置 |
| work | 测试、启动器源码、日志及私有验收截图 |

不要公开分享 data 或 work；验收截图可能包含你的侧栏和任务内容。它们均被源码仓库忽略。分享主题时选择 exports 里的文件。
